# Research Reference Documents

Documents in this directory contain the theoretical background
of the research model.

They are reference sources, not direct implementation specifications.

The authoritative implementation specification is:

docs/model-spec.md

Rules:

1. Do not invent formulas, coefficients, weights or thresholds.
2. Do not resolve contradictions between reference documents silently.
3. If a research decision is ambiguous, record it as unresolved.
4. Implementation code must follow docs/model-spec.md.
5. Reference documents may be used to trace the origin of model decisions.
